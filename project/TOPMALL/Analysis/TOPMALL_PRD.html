4. 발견된 데이터 정합성 이슈 (후속 조치 필요, 이번 작업 범위 아님)

노션 동기화 구조를 만들며 기존 TOPMALL TC 산출물을 점검하는 과정에서 아래 이슈를 발견했습니다. TC 작성까지만 진행하는 프로젝트 특성상 실제 QA 수행에는 지장이 없으나, AGENTS.md 기준과 어긋나는 부분이라 투명하게 기록합니다.

① 캐노니컬 JSON 누락 (모듈 3종, 총 30건) DSP(전시, 10건)·SYS(시스템, 10건)·E2E Bridge(10건) TC가 HTML 뷰어에만 하드코딩되어 있고, 대응하는 TOPMALL_TC_{모듈}.json 캐노니컬 파일이 없습니다. AGENTS.md 10항은 JSON을 유일한 원본(source of truth)으로 규정하므로, 이 30건은 버전관리·변경이력 추적이 되지 않는 상태입니다.
② 기준문서 인용 방식 불일치 CRT/ORD/MY/CLM/PR/PD/MBR 7개 모듈은 reference 필드가 전부 -로, changeHistory에는 "URL 관찰 기반"이라 적혀 있습니다. 실제 정책서가 존재함에도(POL 모듈만 이를 근거로 사용) 나머지 모듈은 정책서와 대조한 기록이 없어, 정책서 내용과 실제 TC가 얼마나 일치하는지 확인되지 않은 상태입니다.
③ CLM 모듈의 근거 원칙 위반 가능성 CLM(취소/반품) 모듈의 changeHistory에는 "보편 이커머스 기준 적용"이라고 명시되어 있어, AGENTS.md 7항이 금지하는 "일반적인 UX 패턴" 근거로 작성되었을 가능성이 있습니다. 반면 정책서에는 취소·환불·반품 시트가 별도로 존재하므로, 실제로는 정책서 대조가 가능했던 영역입니다.

→ 위 3개 이슈는 사용자 확인 후 별도 작업(캐노니컬 JSON 백필, 정책서 재대조)으로 처리하는 것을 권장합니다. TOPMALL은 테스트 실행(Phase 5) 계획이 없으므로 시급성은 낮습니다.
