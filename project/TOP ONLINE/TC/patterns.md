# 재사용 가능한 TC 패턴 (이 프로젝트 전용)

이 프로젝트에서 반복되는 검증 패턴을 정의합니다. AGENTS.md 11-1항 규칙을 따릅니다.
다른 프로젝트의 패턴을 복사해오지 않습니다 — 이 프로젝트의 실제 근거에서 나온 패턴만 기록합니다.

### 패턴: 카드별네비게이션
**적용 대상**: MD's PICK 카드의 "자세히 보기 →" 링크
**절차 템플릿**:
1) MD's PICK 페이지에서 카드{N} "자세히 보기 →" 클릭
**기대결과 템플릿**:
카드{N}과 동일한 상품의 상품상세 페이지로 이동한다
**사용 중인 TC**: TC_DSP_014(카드1), TC_DSP_015(카드2), TC_DSP_016(카드3)

### 패턴: 카드별위시리스트토글
**적용 대상**: 로그인 상태에서 MD's PICK 카드의 "위시리스트 추가" 버튼
**절차 템플릿**:
1) 로그인 상태로 MD's PICK 페이지 진입
2) 카드{N} "위시리스트 추가" 버튼 클릭
**기대결과 템플릿**:
페이지 이동 없이 버튼 라벨이 "위시리스트 제거"(해제 가능 상태)로 즉시 전환된다
**사용 중인 TC**: TC_DSP_018(카드1), TC_DSP_021(카드2), TC_DSP_023(카드3)
