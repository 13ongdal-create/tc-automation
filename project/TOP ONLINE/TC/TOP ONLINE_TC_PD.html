    User Flow Map (상품상세 기준)

    단계내용확인 상태
    1. 상품상세 진입카테고리/전시 목록에서 첫 번째 노출 상품 클릭 → /products/{id} 진입, 기본정보(상품명/코드/가격/이미지) 노출Playwright 관측 확인
    2. 사이즈 선택 → 장바구니 담기사이즈 선택(품절 사이즈는 비활성화) → "장바구니 담기" 클릭 → /cart 반영(게스트/로그인 모두 가능)Playwright 관측 확인
    3. 위시리스트(비로그인)"위시리스트 추가" 클릭 → /login?callbackUrl=%2Fproducts%2F{id} 이동Playwright 관측 확인
    4. 위시리스트(로그인)버튼 라벨 토글(추가↔제거) → 새로고침 후 상태 유지Playwright 관측 확인
    5. 탭/리뷰상세정보·추가 정보·사이즈 & 가이드·리뷰 탭 전환, 리뷰 더보기/필터Playwright 관측 확인
    6. 잘못된 상품ID 접근존재하지 않거나 비정상 형식의 상품번호 접근 시 안내 화면(상태코드는 500, 404 아님)Playwright 관측 확인
    ※ "확인 상태"가 [확인필요]인 단계는 아직 Playwright로 관찰/실행하지 않아 추측으로 채우지 않았습니다 (AGENTS.md 7항).
