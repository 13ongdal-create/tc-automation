MD's PICK 전시 페이지 관찰 리포트

TOP ONLINE 프로젝트 — 정책서·화면설계서 없이 실제 서비스 URL을 코드기반(Playwright)으로 직접 관찰해 작성했습니다. 이 문서에 담긴 모든 수치와 서술은 실측 근거를 가지며, 추정이 섞인 항목은 별도로 표시합니다 (AGENTS.md 7항).

대상 URL /display/mds-pick 관찰일 2026-08-25 근거 유형 코드기반 연계 TC TC_DSP_001~035 (35건)
이 사이트는 기존 "데모사이트" 프로젝트와 동일한 서비스(3TOP)입니다. 다만 프로젝트 격리 원칙(AGENTS.md 16항)에 따라 데모사이트의 기존 TC·결함 기록은 참조하지 않고, 이 페이지만 독립적으로 새로 관찰했습니다.

01페이지 개요

/display/mds-pick는 MD가 큐레이션한 상품 3건을 세로로 나열하는 단일 전시 페이지입니다. 각 카드는 순번(01/02/03), 상품명, 가격(정가·판매가·할인율 또는 단일가), "RECOMMENDATION" 배지, 상품 설명, "자세히 보기" 링크, "위시리스트 추가" 버튼으로 구성됩니다. 장바구니 담기 도선은 이 페이지 어디에도 없습니다.

02데이터 정합성 — 판매가 표시 불일치

MD's PICK 표시 판매가를 각 카드의 상품상세 판매가와 대조한 결과, 할인 중인 카드 2건 모두에서 불일치가 확인되었습니다. 비할인 카드(03)는 정상 일치했습니다.

🚩 DEF_TOP ONLINE_001 — 할인 카드 판매가 표시 불일치

할인 중인 카드에서만 재현되고(2/2) 비할인 카드는 정상(1/1)이라는 점에서, 특정 상품 데이터의 오류가 아니라 전시 컴포넌트가 판매가를 스냅샷하는 과정의 계통적 결함으로 추정됩니다. 카드1의 경우 MD's PICK에 표시된 할인율 배지(7%)조차 자체 표시 판매가(₩110,000) 기준 계산값(≈14.7%)과 어긋나는 반면, 상품상세의 정가·판매가·할인율(₩129,000 / ₩120,000 / 7%)은 내부적으로 정합합니다 — 즉 MD's PICK 쪽의 판매가 값 자체가 원본과 어긋나 있다는 뜻입니다.

03안정성 — 간헐적 500 에러

로그인(/login)과 상품상세(/products/98) 양쪽에서 동일한 시그니처의 서버 오류가 간헐적으로 재현되었습니다.

🚩 DEF_TOP ONLINE_002 — Next.js Server Components 간헐적 500

/login: 6회 시도 중 1회 500 에러 페이지, 1회 무응답(에러 표시 없이 로그인 페이지에 머무름), 4회 정상 — 약 33% 간헐적 실패율.

/products/98: 최초 관찰 5회 중 1회 재현(Error Digest: 795149636). 이후 재검증 32회 중 0회 재현 — 재현율이 낮고 매우 간헐적임을 시사합니다.

재시도 시 대부분 성공하지만, 실패 시 사용자에게 어떠한 안내도 제공되지 않습니다. TC_DSP_034 참조 · P1

04양호 사례

로그인 상태에서 동일 위시리스트 버튼을 거의 동시에 2회 연속 클릭했을 때, 중복 항목 생성 없이 최종 상태가 일관되게 처리됨을 확인했습니다(레이스 컨디션 없음). TC_DSP_035로 회귀 검증에 포함했습니다.

05미확정 사항 — [확인필요]

근거문서 없이 일반적인 이커머스 관행을 기준으로 삼은 항목입니다. 이 사이트 자체의 정책/기획 확인 없이는 결함인지 의도된 설계인지 판단할 수 없어 [확인필요]로 표기했습니다 (AGENTS.md 7항 4번).

SEO — 페이지 고유 타이틀 부재

<title>이 "Top online store" 고정값이며 og:title도 없습니다. 페이지별 고유 타이틀이 SEO 관행상 일반적이나, 이 사이트의 다른 전시 페이지(SALE 등)와 비교 관찰하지 않아 전시 페이지군 전체의 의도된 정책인지 불확실합니다. TC_DSP_028

장바구니 담기 버튼 부재

카드 영역은 물론 페이지 전체에 "장바구니 담기" 버튼이 없습니다(상품상세에는 존재). 즉시 구매 도선 없이 "자세히 보기"/"위시리스트"만 제공하는 것이 이 페이지군의 의도된 설계인지, 아니면 관행상 응당 있어야 할 도선이 누락된 것인지 정책 근거가 없습니다. TC_DSP_033

Empty State 미관찰

현재 3건이 편성되어 있어 "0건 편성" 상태를 재현할 수 없었습니다. Empty State 문구/레이아웃이 정의된 근거문서도 없습니다. BO 접근권한 확보 후 재검토가 필요합니다. TC_DSP_032
