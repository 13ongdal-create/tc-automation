4. 관찰 불가 / 제약

  • 검색 결과 페이지: 검색을 실행하면 /kr/search/results?query=… 로 이동하지만, Cloudflare 봇 방어("Just a moment…", "Unusual activity detected / Access temporarily restricted", 403)에 막혀 결과 목록·정렬/필터·페이지네이션·결과 없음 문구를 관찰하지 못했습니다. 우회는 시도하지 않았습니다. [확인필요] — 결과 화면 스크린샷 또는 접근 가능한 환경이 확보되면 TC를 추가합니다.
  • 일부 API 403: 자동완성 API(/display/search/search-word)가 일부 호출에서 403을 반환했습니다(봇 방어의 영향일 가능성 — 원인 미확정).
  • 콘솔 에러: 관찰 중 net::ERR_BLOCKED_BY_RESPONSE.NotSameOrigin 및 외부 도메인(fbapi.oliveyoung.com) 요청의 CORS 차단 에러가 반복 관찰되었습니다.
