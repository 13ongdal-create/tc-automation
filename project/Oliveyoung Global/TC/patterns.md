### 패턴: 검색어제출이동
**적용 대상**: 검색어를 제출(Enter/검색 버튼/최근 검색어 클릭)했을 때 이동 URL을 검증하는 케이스
**절차 템플릿**:
1) 헤더 검색창에 {검색어} 입력
2) {제출 방식: Enter 키 입력 / "Search" 버튼 클릭}
**기대결과 템플릿**:
2) /kr/search/results?query={URL 인코딩된 검색어} 주소로 이동 (검색 결과 화면 자체는 봇 차단으로 범위 제외)
**사용 중인 TC**: TC_PD_005, TC_PD_006, TC_PD_009, TC_PD_010, TC_PD_017

### 패턴: 공백입력차단
**적용 대상**: 공백만 입력된 검색어의 제출 차단
**절차 템플릿**:
1) 헤더 검색창에 공백만 입력
2) {제출 방식}
**기대결과 템플릿**:
2) 검색 결과 주소로 이동하지 않고 글로벌 메인(/)에 머무름
**사용 중인 TC**: TC_PD_007, TC_PD_008

### 패턴: 최근검색어세팅
**적용 대상**: 최근 검색어 노출/정렬/삭제 검증 전, 검색 이력을 만드는 선행 절차
**절차 템플릿**:
1) {검색어 N개}를 순서대로 검색한 뒤 글로벌 메인으로 복귀
2) 헤더 검색창 클릭(포커스)
**기대결과 템플릿**:
2) "Recent Searches" 영역에 검색어가 최신순(마지막 검색어가 맨 위)으로 노출
**사용 중인 TC**: TC_PD_014, TC_PD_015, TC_PD_016, TC_PD_018, TC_PD_019
