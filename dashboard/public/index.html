TC 업로드

    

      .xlsx — AGENTS.md 2항 컬럼(TC ID/system/대분류/중분류/소분류/화면명/플랫폼/유형/
      테스트항목(시나리오)/기준문서/우선순위/테스트 데이터/사전조건/테스트 수행 절차/기대결과/
      실행결과/담당자/이슈내용 요약/이슈링크/비고) 헤더를 그대로 쓴 시트. 여러 시트/여러 모듈이
      섞여 있어도 됩니다.

      .json — TC 항목 배열([{"tcId":"...", "majorCategory":"...", ...}, ...])
      또는 캐노니컬 파일 전체({"meta":{...},"items":[...]}, TC 뷰어의 "JSON 저장"이
      만드는 형식 그대로) — 필드명은 엑셀 헤더가 아니라 tcId/majorCategory/steps/expected 같은
      캐노니컬 스키마 이름을 그대로 씁니다.

      두 형식 모두 TC ID가 이미 등록된 값이면 수정, 비어있으면 대분류를 기준으로 신규 추가되며,
      값이 채워진 칸/필드만 반영되고 나머지는 기존 값을 그대로 둡니다.

      단, TC ID가 같아도 대/중/소분류·테스트항목 중 값이 있는 게 서로 다르면 같은 TC의 수정이
      아니라 우연히 ID만 겹친 별개 케이스로 보고, 기존 TC는 그대로 둔 채 새 TC ID로 분리 생성합니다
      (결과 화면에 어떤 항목이 분리 생성됐는지 안내됩니다).
